# 004 — สมุดแท็บสวมชุดเกม (arcade stage planner)

## Design stance
โครงหลักยังเป็น **mockup 002 (สมุดแท็บรายวัน)** เต็มตัว — กระดาษครีม เส้นมาร์จิ้นแดง รูเจาะ แท็บสีตามเมือง — แต่ "สวมชุดเกม": HUD ยศ/XP แปะเหมือนสติกเกอร์การ์ดเกม ปุ่มทุกปุ่มเป็นแบบอาร์เคดขอบหนา มีหน้าปกเกมพร้อมปุ่ม START และแมวนำทาง **น้องเฉาก๊วย** (แมวดำ ชื่อขนมดำ) วาดด้วย SVG

## กติกาเกม
- ติ๊กภารกิจ 1 รายการ = **+10 XP** · เช็คครบวันนั้น = **โบนัส +50 XP** (แบนเนอร์ CLEAR! + ตราปั๊ม)
- ยศ 5 ระดับที่ 0/100/250/450/650 XP (ค่าสูงสุดทริปนี้ 1150 XP — 65 ภารกิจ + โบนัส 10 วัน)
- ติ๊กต่อเนื่องภายใน 6 วิ ขึ้น **คอมโบ ×N** (ชิปเสริม ไม่กะพริบ)
- สถานะเก็บ localStorage (`chaokuay-game-v03`) — เปิดซ้ำเล่นต่อ รีเซ็ตได้ที่ท้ายหน้าปก

## สีเมือง (จากแผนจริง)
โตเกียว `#e8485f` · คานาซาวา `#f0a12e` · ฟุกุอิ `#27a874` · โทยามะ+คุโรเบะ `#3b8fd8` · คุซัทสึ `#8b6ad6` · คินุกาวะ/นิกโกะ `#ef7b2f` — ตัวอักษรบนแท็บเลือก ขาว/ดำอุ่น ตามคอนทราสต์จริงของแต่ละสี

## Trade-offs
- Strong at: เล่นสนุกไปกับทริป เห็นความคืบหน้าชัด เด็กและผู้สูงวัยใช้ร่วมกันได้ (ตัวใหญ่ ปุ่มโต คอนทราสต์สูง อนิเมชันเบา + respect prefers-reduced-motion)
- Weak at: ความ "เกม" กินที่บางหน้า — ต้องระวังไม่ให้กลืนความเป็นสมุดอ้างอิง; สถานะเช็คอยู่ใน localStorage เครื่องละเครื่อง (ไม่ sync ข้ามเครื่อง — ตั้งใจให้เป็นเกมส่วนตัว)

## Best for
ช่วงเที่ยวจริง + ช่วงเตรียมทริป — ทุกคนในครอบครัวแย่งติ๊กภารกิจกันเอง

## เทคนิค
- ไฟล์เดียว `index.html` · ฟอนต์โหลด Google Fonts (mockup ใช้ CDN ได้ — ตอนยกไปแอปจริงต้องฝัง woff2 base64 ตามกติกา trip-kit)
- ข้อมูลฝังใน `DAYS[]` — แก้แผนแก้ที่เดียว หน้าอัปเดตเอง · **v0.3: รหัสจอง (โรงแรม/เครื่องบิน/รถเช่า) ไม่อยู่ในไฟล์แบบข้อความล้วน** — ถูกเข้ารหัส AES-256-GCM (PBKDF2-SHA256 400k รอบ) ฝังเป็น `VAULT` ปลดล็อกด้วยรหัสลับครอบครัวผ่าน WebCrypto (ต้อง https / localhost) — จึงโฮสต์เป็นลิงก์สาธารณะได้; เปลี่ยนรหัสได้ด้วย `GAME_PW=... node build-vault.mjs`
- คีย์บอร์ด: ← → เลื่อนวัน · แท็บมี aria-current · เช็คบ็อกซ์เป็น input จริง (อ่านจอได้)
- **เปิดจากแชท**: ป้ายสแตติก `.ql-help` บนหน้าปกโชว์เองเมื่อ JS ไม่ทำงาน (พรีวิวไฟล์ใน Telegram/iOS) และซ่อนเองเมื่อเกมรันได้ · เปิดผ่าน**ลิงก์**ในแอปแชทจะขึ้นโอเวอร์เลย์ปุ่มยักษ์กระโดด Chrome (Android `intent://`, iOS `googlechrome://`) มีปุ่ม "เล่นในแอปนี้ต่อ" สำรองเสมอ
